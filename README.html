HLHN AI Chat Mod

A BepInEx mod for He Lives Here Now by EvilGuest, that integrates AI-powered dialogue and interactive companionship into the game. Chat seamlessly with NPCs — the four main characters (Katherine, Susan, Stacy and Laura) as well as the neighbourhood secondary characters. AI responses play through the game's native speech bubbles and dialogue boxes, complete with dynamic facial expressions, emotional reactions, and in-game physical actions.

BepInEx 5.x .NET Standard 2.1 HLHN v6.4+

✨ Features

🤖

Multiple AI Backends

Supports local models via LM Studio / Ollama (recommended: defyma85/gemma-4-E4B-it-ultra-uncensored-heretic-Q4_K_M_gguf) and cloud models via Google Gemini API.

💬

Radial Menu & Native Dialogue

Approach any NPC, press E to open the radial interaction menu, and select AI. Chat using the game's native text input with real-time typing and NPC portraits.

🎭

Dynamic Facial Reactions

NPCs react visually to conversation sentiment: positive compliments trigger happy expressions; insults or negative replies trigger angry or annoyed reactions.

📖

In-Game Tutorial System

Full 5-page illustrated tutorial accessible directly from the pause menu (ESC → Tutorial → AI chat mod). Images loaded from BepInEx/config/AIChat/.

🧠

Deep Character Context

The AI is aware of each NPC's personality, trust level, submission/desire stats, clothing status, and nearby environment.

🎮

Autonomous Action Commands

The AI can execute game actions embedded in its responses:

  • Follow / Stop following
  • Go to a room or perform chores
  • Put on / Remove clothing
  • Kiss, facial expressions, emotions
🌐

Multilingual Support

Player messages are understood in English, Spanish, and any language supported by the AI model.

💾

Persistent Memory & Milestones

Conversation histories, relationship milestones (intimacy, virginity, orgasms), and character summaries are automatically saved to disk.

📦 Installation

First Steps — Download the mod

  1. Download the latest HLHN_AIChatMod.zip from the releases page.
  2. Unzip and copy all the files from the HLHN_AIChatMod folder into the He Lives Here Now game folder (if it asks you to replace, replace).

Second Step — Configure

For Google Gemini (Not recommended) — Interactions with the AI are NSFW and violate the API's terms of use. Use at your own risk; create a new Google account or use one you don't normally use to generate the API key.

Go to aistudio.google.com/api-keys and create an API key (you must create or select any project), copy the key, and paste it into the "Gemini API Key" field in the AI Chat window (Ctrl + V).

For Local AI (Ollama / Gemma) — Recommended
  1. Download Ollama from ollama.com/download and install.
  2. Open a PowerShell terminal, copy and paste this command and press Enter:
    ollama run defyma85/gemma-4-E4B-it-ultra-uncensored-heretic-Q4_K_M_gguf
  3. Wait for the download and extraction to complete. Upon success, it will ask you to send a message; simply type /bye or close the terminal.
  4. Open the game and load a save or start a new game, press F9 and switch to the Ollama provider in the config panel and enter the model name (in this case defyma85/gemma-4-E4B-it-ultra-uncensored-heretic-Q4_K_M_gguf). It will be set by default.
Note: Make sure Ollama is running on your PC and that you have downloaded a model. Local AI models are resource-intensive. Ensure you have a mid-to-high-end PC. Avoid using extremely lightweight or older models, as responses will degrade.

Third Step — Use

  1. Open the game, approach a girl, press E and select the "AI" option.
  2. You can watch a brief tutorial on how to use the mod in the pause menu: press ESC → Tutorial → AI Chat Mod.

🎮 How to Play

1. Native In-Game Interaction (Immersive)

  1. Walk up to any character or NPC.
  2. Press E to open the interaction menu.
  3. Select the AI option.
  4. The dialogue box opens.
  5. Type your message and press Enter to send.
  6. The NPC answers, plays facial reactions and may perform actions.
  7. Press Space or Enter to advance dialogue, or press Space while your input box is empty to close it and resume free movement.

2. Full Chat & Debug Window (F9)

  • Press F9 at any time to open the complete IMGUI window.
  • Switch between Chat, Memory, Settings, and Debug tabs.
  • Inspect character trust, submission, desires, and current routine tasks.

3. In-Game Tutorial

  • Press ESC to open the pause menu.
  • Click Tutorial and choose AI chat mod.
  • Browse the 5 illustrated pages for in-depth guidance on setup, commands, and conversation tips.

🔧 Troubleshooting

IssueResolution
The chat window doesn't open with F9 Ensure BepInEx 5 is installed and HLHN_AIChatMod.dll is inside BepInEx/plugins/. Check BepInEx/LogOutput.log.
Interaction menu doesn't show "AI" option Stand in front of the NPC, then press E. If you press E when the girl has her back to you or is turned to the side, the AI option won't appear.
AI returns empty or slow replies For local AI, ensure LM Studio or Ollama is running and the model is loaded. Depending on your computer, the screen may freeze and responses may be slow. For Gemini, verify your API key in Settings (F9 → CONFIG); on some occasions, the Gemini service may be busy.
Tutorial images are missing or white Verify that 1.jpg through 5.jpg (or .png) are placed in BepInEx/config/AIChat/.
UI mod turns transparent after scene change IMGUI textures auto-reload on scene load; if needed, click Force Reinit Styles under the Debug tab.
